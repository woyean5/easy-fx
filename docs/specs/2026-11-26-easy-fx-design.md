# Easy FX 설계 문서

작성일: 2026-11-26 · 상태: 승인됨

## 1. 왜 만드나

주식 투자는 20대에게 익숙해졌지만 FX(외환) 거래는 여전히 낯설다. "달러가 오르면 나에게 뭐가 좋은지", "레버리지가 왜 위험한지"를 몸으로 겪어볼 곳이 없다.
Easy FX는 **한 번 켜서 5분 안에 끝나는 판**으로, 실제 과거 환율을 빠르게 돌리며 FX와 레버리지를 경험하게 하는 모의투자 앱이다.

**성공의 모습:** 처음 온 20대 사용자가 가이드 없이도 첫 판을 5분 안에 끝내고, 결과 화면을 보고 "왜 벌었는지/잃었는지"를 한 문장으로 말할 수 있다.

## 2. 목표 / 비목표 / 반목표

**목표**
- 짧은 판(라운드) 방식: 과거 실제 환율 한 달치를 약 5분에 재생
- 레버리지 선택과 그 결과(강제청산 포함)를 극적으로 체감
- 자세한 가이드: 용어마다 ⓘ 설명, 한국어 + 영어 용어 병기
- 애플 기본 주식 앱처럼 단순한 화면
- 기록과 랭킹 (1단계: 내 기기 안, 2단계: 친구와)

**비목표 (1단계에서 안 함)**
- 실제 돈 거래, 실시간 환율
- 앱스토어용 네이티브 앱
- 로그인·서버·친구 랭킹 (2단계로 미룸)
- 여러 포지션 동시 보유, 지정가 주문, 손절 주문 등 고급 기능

**반목표 (기능은 돌아가도 이러면 실패)**
- 화면에 버튼과 숫자가 가득해서 증권사 앱처럼 복잡해지는 것
- 높은 레버리지가 "쉽게 큰돈 버는 방법"처럼 보이는 것. 극적인 연출은 **잃는 쪽**에 쓴다.
- 판 하나가 5분을 크게 넘겨 지루해지는 것

## 3. 제약

- 이 작업 환경은 Linux라서 iOS 네이티브 앱을 빌드할 수 없다. 휴대폰 웹앱(PWA)으로 만든다.
- 과거 환율 데이터는 무료로 받을 수 있는 곳(Dukascopy, HistData 등)을 쓰되, **앱에 넣어 배포해도 되는지 이용약관을 확인**해야 한다.
- 투자 권유가 아님을 앱 안에 명시한다.

## 4. 접근 방법

| 방법 | 장점 | 단점 |
|---|---|---|
| **A. 휴대폰 웹앱만 (서버 없음)** ← 선택 | 가장 빠르고 단순, 핵심 재미 검증에 집중 | 랭킹은 내 기록끼리만 |
| B. 웹앱 + 작은 서버 (Supabase 등) | 닉네임 기반 친구 랭킹 | 설정·개발 시간 증가 |
| C. Claude 아티팩트 페이지 | 공유 랭킹을 서버 없이 바로 | claude.ai 안에서만 열려 실제 앱으로 부적합 |

**결정:** A로 1단계를 만들고, 2단계에서 B로 확장한다. 저장소 접근을 한 곳(`storage` 모듈)으로 모아서, 나중에 서버를 붙여도 화면 코드는 바꾸지 않게 한다.

## 5. 정해진 내용

### 5.1 한 판의 흐름
1. **시나리오 선택**: 카드 4개 중 하나
2. **레버리지 선택**: 1배 / 2배 / 3배 (가이드를 마치면 10배·30배 열림)
3. **재생**: 한 달치 환율이 약 5분 동안 흘러감. 그동안 매수/매도/청산
4. **결과**: 수익률, 차트 위 내 매매 지점, "그때 실제로 무슨 일이 있었나" 해설 3~4문장, 다시 하기 버튼

### 5.2 시나리오 (첫 버전 4개)
| 이름 | 통화쌍 | 기간 | 이야기 |
|---|---|---|---|
| 엔화 대폭락 | USD/JPY | 2022년 9~10월 | 미국 금리 인상, 일본 정부 개입 |
| 코로나 달러 쇼크 | EUR/USD 또는 AUD/USD | 2020년 3월 | 위기 때 달러로 몰리는 돈 |
| 브렉시트의 밤 | GBP/USD | 2016년 6월 | 국민투표 결과 하룻밤 급락 |
| 엔캐리 청산 | USD/JPY | 2024년 7~8월 | 하루 만에 뒤집힌 시장 |

USD/KRW는 한국 사용자에게 가장 와닿지만 무료 분 단위 데이터가 드물어 보류. 구할 수 있으면 추가한다.

### 5.3 거래 규칙 (단순화한 실제 FX)
- 시작 잔고 $10,000
- 한 번에 포지션 하나만. **매수**(오를 것) 또는 **매도**(내릴 것), 금액은 슬라이더로
- 필요 증거금 = 거래 금액 ÷ 레버리지
- 통화쌍마다 고정 스프레드 적용 (실제와 비슷한 값)
- **강제청산**: 증거금 유지율이 50% 아래로 내려가면 자동 청산
- 강제청산되면 그 판은 바로 끝나고 결과 화면으로 간다
- 판 도중 언제든 직접 청산하고 새 포지션을 잡을 수 있음. 판이 끝나면 남은 포지션은 마지막 가격으로 자동 청산

### 5.4 강제청산 연출 (극적으로)
- 화면이 빨갛게 번쩍이고 살짝 흔들림, 지원 기기에서는 진동
- 잔고 숫자가 빠르게 떨어지는 애니메이션
- 큰 글씨 "강제청산 (Margin Call)" + "레버리지 30배에서는 3.3%만 반대로 움직여도 원금이 사라져요" 같은 한 줄 설명
- 바로 "같은 시나리오를 낮은 레버리지로 다시 하기" 버튼

### 5.5 가이드
- **ⓘ 설명**: 레버리지, 스프레드, 증거금, 강제청산, pip 등 용어 옆 ⓘ를 누르면 아래에서 올라오는 짧은 설명 카드. 표기는 "레버리지 (Leverage)"처럼 한국어 + 영어
- **입문 가이드**: 카드 5~6장 분량. 다 읽으면 10배·30배 레버리지 해금
- 첫 판에서만 화면 위에 "여기를 눌러 매수해요" 같은 짧은 안내를 띄움

### 5.6 디자인
- 애플 주식 앱 스타일: 검정 배경(라이트 모드 지원), 시스템 폰트, 초록(상승)·빨강(하락) 두 색만 강조
- 화면은 세 개: **홈**(시나리오 목록 + 내 기록), **거래**(큰 선 차트 + 가격 + 매수/매도 두 버튼), **결과**
- 한 화면에 주요 버튼은 두 개 이하

```
┌─────────────────────────┐
│ 엔화 대폭락   USD/JPY  x3│
│ 144.82          ▲ +0.42%│
│                         │
│      ~~~╱╲__╱╲~~~       │
│ ──────────────── 2:41 남음│
│ 잔고 $10,240  ⓘ 증거금 68%│
│  [  매수  ]   [  매도  ] │
└─────────────────────────┘
```

### 5.7 기록과 랭킹 (1단계)
- 내 기기(localStorage)에 판마다 시나리오, 레버리지, 수익률, 날짜 저장
- 홈 화면에 시나리오별 최고 수익률, 전체 판 수, 강제청산 횟수
- 2단계에서 같은 시나리오끼리 친구 랭킹. 로그인 없이 **닉네임만** 입력 (사용자 결정). 1단계에서도 첫 실행 때 닉네임을 받아 저장해 둔다

### 5.8 기술 선택
- React + TypeScript + Vite, PWA (홈 화면에 추가 가능)
- 차트: TradingView lightweight-charts (선 차트)
- 데이터: 빌드 전에 스크립트로 내려받아 15분 봉 정도로 줄인 JSON을 앱에 포함 (한 달 ≈ 2,000개 점 → 5분 재생 시 초당 약 7개)
- 거래 계산(증거금, 손익, 강제청산)은 화면과 분리된 순수 함수로 만들고 테스트를 붙인다

## 6. 만드는 사람에게 맡기는 것
- 정확한 스프레드 값, 재생 속도 미세 조정, 일시정지 허용 여부
- 해설 문구와 가이드 카드의 구체적인 내용 (사실 확인 필수)
- 데이터 출처 최종 선택 (이용약관 확인 후)
- 배포 위치 (Vercel, Netlify 등)

## 7. 이 문서에서 Claude가 정한 것 (확인 필요)
- 접근 방법 A로 시작 (사용자가 명시적으로 고르지는 않음)
- 시나리오 4개와 그 목록
- 기본 레버리지 1·2·3배, 가이드 완료 시 10·30배 해금
- 강제청산 기준 증거금 유지율 50%
- 포지션은 한 번에 하나

## 8. 추가: 실시간 모드 + 애플 스타일 다듬기 (2026-11-26 승인)

**왜:** 시나리오 연습 다음 단계로, 일반 FX 거래처럼 지금 시세로 사고팔아 보고 싶다는 사용자 요청.

**시세 출처 (사용자 승인: Kraken + 원/달러 추가)**
| 통화쌍 | 출처 | 갱신 | 차트 과거 데이터 |
|---|---|---|---|
| EUR/USD, GBP/USD, AUD/USD | Kraken 공개 API (`/0/public/Ticker`, `/0/public/OHLC`) | 3초 | 있음 (15분/60분/240분봉) |
| USD/JPY, USD/KRW | Coinbase 환율 (`/v2/exchange-rates?currency=USD`) | 60초 | 없음. 앱이 켜져 있는 동안 받은 시세를 기기에 쌓아서 그림 |

- Claude 결정: USD/JPY는 Kraken 거래가 하루 수십 건뿐이라 가격이 실제와 2엔 이상 어긋나서 Coinbase로 옮김.
- 시세는 중간값(mid)만 쓰고, 스프레드는 앱의 고정값을 붙인다 (USD/KRW `100` pip, 1pip=0.01원).

**실시간 계좌**
- 시나리오와 별개의 가상 계좌 $10,000. 기기에 저장되어 앱을 닫아도 유지.
- 통화쌍마다 포지션 하나, 여러 통화쌍 동시 보유. 증거금은 계좌 전체로 계산(일반 FX의 교차 증거금): 유지율 = 자산 ÷ 사용 증거금 합계 × 100, `< 50%`면 모든 포지션 강제청산.
- 새 주문은 여유 증거금(자산 − 사용 증거금) 안에서만.
- 앱을 다시 열 때: 마지막 접속 이후 Kraken 봉의 불리한 쪽 극값(매수=저가, 매도=고가)으로 유지율을 다시 계산해, 닿았으면 그 시각에 강제청산 처리. Coinbase 통화쌍은 과거 봉이 없어 현재가로만 확인 (Claude 결정, 한계로 명시).
- 시세가 1시간 넘게 멈춰 있으면 "거래 쉬는 시간"으로 표시하고 주문을 막는다.
- [계좌 초기화]: 잔고 $10,000로 되돌리고 **실시간 거래 기록도 지운다** (사용자 결정). 시나리오 기록은 유지.

**애플 주식 앱 스타일**
- 하단 탭 3개: 실시간 / 연습 / 기록
- 실시간 탭: 큰 제목 + 날짜, 계좌 요약, 관심 종목형 목록(굵은 통화쌍 + 회색 한글 이름 + 작은 추세선 + 가격 + 등락 배지)
- 통화쌍 상세: 아래에서 올라오는 전체 화면 시트, 1일/1주/1개월 선택, 차트를 훑으면 그 시점 가격 표시, 레버리지 선택, 매수/매도
- 기록 탭: 실시간 거래 내역 + 시나리오 기록, 계좌 초기화
- 연습 탭: 기존 시나리오 목록을 둥근 그룹 목록으로

**비목표:** 지정가·손절 주문, 스왑 이자, 서버 저장

## 9. 추가: 원화 기준 계좌, 그림 가이드, 캐나다 달러 (2026-11-27)

**사용자 요청:** 주 단위를 원화로, 가이드 설명에 그림, 캐나다 달러 추가.

- **원화 계좌 (Claude 해석: "주 단위" = 계좌의 기본 통화)**: 실시간과 연습 모두 시작 자산 **₩10,000,000**. 증거금, 잔고, 손익을 원화로 표시한다.
  - 계산: 증거금(원) × 레버리지 ÷ 원/달러 = 거래 금액(달러). 손익은 달러로 계산한 뒤 × 원/달러로 원화 환산.
  - 원/달러: 실시간은 Coinbase의 현재 USD/KRW. 연습은 판 시작 시점의 USD/KRW로 고정(받지 못하면 1,350).
  - 원/달러 시세가 없으면 실시간 주문을 막는다.
  - 기존 달러 기준 실시간 계좌는 원화 계좌로 새로 시작한다 (Claude 결정, 출시 직후라 영향 작음).
- **그림 가이드**: 입문 가이드 6장마다 그 개념을 보여주는 인라인 SVG 그림.
- **USD/CAD**: Kraken `ZUSDZCAD` (하루 약 9천 건 체결, Coinbase와 가격 일치). 실시간 목록 + "최근 한 달 미국달러/캐나다달러" 연습 시나리오. 스프레드 1.5pip.
