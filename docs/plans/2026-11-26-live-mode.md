# Easy FX 실시간 모드 + 애플 스타일 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** 지금 시세로 거래하는 실시간 모드와 애플 주식 앱 스타일의 탭 구조를 추가한다.
**Architecture:** 시세 수집(`live/quotes.ts`)과 계좌 계산(`live/account.ts`)을 순수 모듈로 분리하고 테스트한다. 화면은 탭(`App`) → 실시간/연습/기록. 기존 `engine.ts`의 `quote`, `unrealizedPnl`을 재사용한다.
**Tech Stack:** 기존과 동일
**Spec:** `docs/specs/2026-11-26-easy-fx-design.md` 8절

## Global Constraints
- 갱신: Kraken 3초, Coinbase 60초. 화면이 숨겨지면 멈춤
- 강제청산 `< 50%` (계좌 전체), 시작 잔고 $10,000, 레버리지 사다리 1·2·3·10·30 (10·30은 가이드 후)
- 저장 키 `easyfx:live` (계좌), `easyfx:liveHistory` (거래 내역), `easyfx:ticks:<PAIR>` (Coinbase 통화쌍 시세, 최근 2,000개)
- 1시간 넘게 시세가 멈추면 주문 불가

## Review Focus
1. 시세 요청 실패/오프라인: 마지막 시세를 유지하고 "연결 끊김" 표시, 앱이 죽지 않음 (Task 1)
2. 앱을 며칠 닫았다 열기: 그동안 강제청산선을 지났으면 청산 처리 (Task 2)
3. 여유 증거금을 넘는 주문: 거부 (Task 2)
4. 이미 포지션이 있는 통화쌍에 다시 주문: 무시 (Task 2)
5. 휴장 중 주문: 막힘 (Task 1 `isStale`)

### Task 1: 시세 모듈
Files: `src/live/quotes.ts`, test `src/live/quotes.test.ts`
Produces:
- `type LivePair = 'EURUSD' | 'GBPUSD' | 'AUDUSD' | 'USDJPY' | 'USDKRW'`, `LIVE_PAIRS: LivePair[]`, `PAIR_NAME_KO: Record<LivePair,string>`
- `parseKrakenTicker(json): Partial<Record<LivePair, number>>` (mid=(a+b)/2, 키 `ZEURZUSD`→EURUSD, `ZGBPZUSD`→GBPUSD, `AUDUSD`→AUDUSD)
- `parseCoinbaseRates(json): Partial<Record<LivePair, number>>` (JPY, KRW)
- `parseKrakenOhlc(json): Candle[]`, `interface Candle { t: number; o: number; h: number; l: number; c: number }`
- `fetchQuotes(): Promise<Partial<Record<LivePair, number>>>`, `fetchCandles(pair, interval, since?): Promise<Candle[]>`
- `isStale(lastCandleT: number, now: number): boolean` (> 3600초)
Tests: 실제 응답 모양의 고정 JSON으로 파싱 결과, `error`가 비어 있지 않으면 throw, isStale 경계.

### Task 2: 실시간 계좌
Files: `src/live/account.ts`, test `src/live/account.test.ts`; `engine/types.ts`의 `Pair`에 `'USDKRW'` 추가, `SPREAD_PIPS.USDKRW = 100`
Produces:
- `interface LivePosition extends Position { openedAt: number }`, `interface LiveAccount { balance: number; positions: Partial<Record<LivePair, LivePosition>>; lastSeen: number }`
- `interface ClosedTrade { pair; side; leverage; margin; pnl; openedAt; closedAt; reason: 'manual'|'stopout' }`
- `newLiveAccount(now)`, `usedMargin(acc)`, `liveEquity(acc, mids)`, `freeMargin(acc, mids)`, `liveMarginLevel(acc, mids): number|null`
- `openLive(acc, pair, side, margin, leverage, mids, now): LiveAccount` (포지션 있음/margin<=0/margin>freeMargin → 같은 객체)
- `closeLive(acc, pair, mid, now, reason): { acc; trade: ClosedTrade | null }`
- `stopOutAll(acc, mids, now): { acc; trades: ClosedTrade[] }`
- `replayOffline(acc, candles: Partial<Record<LivePair, Candle[]>>, mids, now): { acc; trades; stoppedAt: number | null }`
Tests: 교차 증거금 유지율, 여유 증거금 초과 거부, 같은 통화쌍 재주문 무시, 30배 두 포지션 중 하나 폭락 시 전체 청산, 오프라인 봉 저가로 청산(stoppedAt=그 봉 시각), 봉이 안전하면 그대로.
