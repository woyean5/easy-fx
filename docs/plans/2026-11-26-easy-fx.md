# Easy FX 1단계 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 과거 실제 환율 한 달치를 5분에 재생하며 레버리지 매매를 해보는 휴대폰 웹앱(PWA) Easy FX 1단계를 만든다.

**Architecture:** 서버 없는 React 단일 페이지 앱. 거래 계산(`engine`)과 재생(`replay`)은 화면과 분리된 순수 TypeScript 모듈로 두고 테스트한다. 저장은 `storage` 모듈 하나로만 한다. 2단계에서는 이 모듈 뒤에 서버를 붙인다. 시나리오 데이터는 빌드 전에 스크립트로 받아 `public/scenarios/*.json`에 넣는다.

**Tech Stack:** Vite 6, React 18, TypeScript, Vitest, lightweight-charts 4, vite-plugin-pwa, dukascopy-node(데이터 스크립트 전용)

**Spec:** `docs/specs/2026-11-26-easy-fx-design.md`

## Global Constraints

- 시작 잔고 `$10,000`. 계좌 통화는 USD.
- 레버리지 기본 `1, 2, 3`배. 입문 가이드 완료 시 `10, 30`배 해금.
- 강제청산: 증거금 유지율(자산 ÷ 사용 증거금 × 100) `< 50%`. 강제청산되면 그 판은 즉시 종료된다.
- 포지션은 동시에 하나만 잡을 수 있다. 판이 끝날 때 남은 포지션은 마지막 가격으로 자동 청산한다.
- 한 판의 재생 시간은 `300초`.
- 고정 스프레드(pip): USD/JPY `1.0`(1pip=0.01), EUR/USD `0.8`, AUD/USD `1.0`, GBP/USD `1.2`(1pip=0.0001)
- 용어 표기는 "한국어 (English)" 형식. 예: `레버리지 (Leverage)`
- 색: 상승 `#30d158`, 하락 `#ff453a`. 시스템 폰트(`-apple-system, BlinkMacSystemFont, "Apple SD Gothic Neo", sans-serif`)를 쓰고, 기본은 다크, `prefers-color-scheme: light`면 라이트.
- 한 화면에 주요 버튼은 두 개까지.
- 앱 하단 고정 문구: `모의투자 앱이며 투자 권유가 아닙니다.`
- 가격 데이터는 실제 과거 데이터만 쓴다. 받지 못하면 임의로 만들지 말고 멈춰서 보고한다.

## Review Focus

1. **판 도중 앱을 내리거나 화면이 꺼짐**: 재생이 일시정지되고, 돌아오면 이어서 진행해야 한다. 뒤에서 몰래 흘러가 강제청산되면 안 된다. (Task 3)
2. **사생활 보호 모드라 localStorage를 못 쓰는 경우**: 앱이 죽지 않고 기록 없이 동작해야 한다. (Task 4)
3. **매수 버튼을 빠르게 두 번 누름**: 포지션이 두 개 생기거나 증거금이 두 번 빠지면 안 된다. (Task 1)
4. **슬라이더가 0이거나 금액이 잔고보다 큼**: 주문이 거부되고 버튼이 비활성화돼야 한다. (Task 1)
5. **아이폰 SE 같은 작은 화면(375×667)**: 가로 스크롤이 없고 매수/매도 버튼이 한 화면에 보여야 한다. (Task 5)

### Task 1: 프로젝트 생성 + 거래 계산 엔진

**Files:**
- Create: `package.json`, `vite.config.ts`, `tsconfig.json`, `index.html` (Vite react-ts 템플릿)
- Create: `src/engine/types.ts`, `src/engine/engine.ts`
- Test: `src/engine/engine.test.ts`

**Interfaces:**
- Produces:
  - `type Pair = 'USDJPY' | 'EURUSD' | 'AUDUSD' | 'GBPUSD'`
  - `type Side = 'buy' | 'sell'`
  - `interface Position { side: Side; margin: number; leverage: number; entry: number; units: number }`
  - `interface Account { balance: number; position: Position | null }`
  - `const START_BALANCE = 10000`, `const STOP_OUT_LEVEL = 50`, `const SPREAD_PIPS: Record<Pair, number>`, `pipSize(pair: Pair): number`
  - `quote(pair: Pair, mid: number): { bid: number; ask: number }`
  - `open(acc: Account, pair: Pair, side: Side, margin: number, leverage: number, mid: number): Account`: `position`이 이미 있거나 `margin <= 0`이거나 `margin > balance`이면 같은 객체를 그대로 돌려준다.
  - `unrealizedPnl(pair: Pair, pos: Position, mid: number): number` (USD)
  - `equity(acc: Account, pair: Pair, mid: number): number`
  - `marginLevel(acc: Account, pair: Pair, mid: number): number | null` (포지션 없으면 null)
  - `close(acc: Account, pair: Pair, mid: number): Account`
  - `shouldStopOut(acc: Account, pair: Pair, mid: number): boolean`

**계산 규칙:**
- 거래 금액 = margin × leverage (USD). 진입가는 buy면 ask, sell이면 bid. 청산가는 그 반대쪽 호가.
- units(기준통화 수량): 기준통화가 USD면(USDJPY) 거래 금액 그대로, 기준통화가 USD가 아니면 거래 금액 ÷ 진입가.
- 손익(호가통화) = units × (청산가 − 진입가) × (buy ? 1 : −1). 호가통화가 USD가 아니면(JPY) 청산가로 나눠 USD로 바꾼다.
- `open`할 때 balance는 그대로 두고, margin은 사용 증거금으로만 잡는다. `close`하면 balance += 손익.

```ts
const acc0 = { balance: 10000, position: null };
test('quote applies half spread each side', () => {
  const q = quote('USDJPY', 150);
  expect(q.bid).toBeCloseTo(149.995, 6);
  expect(q.ask).toBeCloseTo(150.005, 6);
});
test('USDJPY buy 3x then +1 yen ≈ +$198', () => {
  const a = open(acc0, 'USDJPY', 'buy', 10000, 3, 150);
  expect(a.position!.units).toBe(30000);
  expect(unrealizedPnl('USDJPY', a.position!, 151)).toBeCloseTo(30000 * (150.995 - 150.005) / 150.995, 2);
});
test('EURUSD sell profits when price falls', () => {
  const a = open(acc0, 'EURUSD', 'sell', 1000, 2, 1.1);
  expect(unrealizedPnl('EURUSD', a.position!, 1.09)).toBeGreaterThan(0);
});
test('second open is ignored (double tap)', () => {
  const a = open(acc0, 'USDJPY', 'buy', 1000, 1, 150);
  expect(open(a, 'USDJPY', 'buy', 1000, 1, 150)).toBe(a);
});
test('rejects margin <= 0 or > balance', () => {
  expect(open(acc0, 'USDJPY', 'buy', 0, 1, 150)).toBe(acc0);
  expect(open(acc0, 'USDJPY', 'buy', 10001, 1, 150)).toBe(acc0);
});
test('30x stop-out triggers below 50% margin level', () => {
  const a = open(acc0, 'USDJPY', 'buy', 10000, 30, 150);
  expect(shouldStopOut(a, 'USDJPY', 149)).toBe(false); // ≈ -$2,000
  expect(shouldStopOut(a, 'USDJPY', 147)).toBe(true);  // ≈ -$6,100
});
test('close realizes pnl into balance and clears position', () => {
  const a = close(open(acc0, 'GBPUSD', 'buy', 1000, 1, 1.3), 'GBPUSD', 1.3);
  expect(a.position).toBeNull();
  expect(a.balance).toBeLessThan(10000); // 스프레드만큼 손해
});
```
